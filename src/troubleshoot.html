Troubleshoot

If you're experiencing issues with SPP New Tab, you can try these things to fix them:

Try this step first:

This won't delete any data. Any other new tabs that are open will load into Chrome's default one, you can close them or press back when they are focused to get back to SPP New Tab.

If you're filing an issue report:

Collect support data...
We may ask for your support data to help us figure out your issue. If asked for it, you can use this button to get it.

If all else fails:

Clear extension data...
This option WILL delete your extension data. In some extreme cases, this may be the only option that works. You can clear your local and cloud data separately.
