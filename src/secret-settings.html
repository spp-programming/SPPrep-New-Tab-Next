Cloud

Cloud settings are managed separately from local settings, so you need to use the buttons below to sync them.

When you save to the cloud, all changes on this page will be uploaded, even though you haven't saved them locally yet.

The buttons on this page only handle the secret settings. If you want to use cloud settings for non-secret (regular settings), you will need to use the corresponding buttons on the regular settings page.

IMPORTANT! Loading from the cloud will OVERWRITE your local settings.


Custom backgrounds won't be saved to the cloud. Chrome/Firefox sync needs to be on for cloud settings to work.
The extension will be reloaded once you save. Any other new tabs that are open will load into Chrome's default one, you can close them or press back when they are focused to get back to SPP New Tab.
